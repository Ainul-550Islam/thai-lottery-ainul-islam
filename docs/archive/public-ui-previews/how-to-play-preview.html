Detailed Thai Lottery Bet Types

Understand the exact winning conditions and odds for each market.

3-Digit Top (3 ตัวบน)

900x Payout

Matches the last 3 digits of the official 1st Prize exactly in position.

Example 1st Prize = 843921 → Winning # = 921

3-Digit Tod (3 ตัวโต๊ด)

150x Payout

Matches the last 3 digits of the 1st Prize in ANY order / permutation.

Example 1st Prize = 843921 → 921, 912, 129... all win

2-Digit (2 ตัวบน / ล่าง)

90x Payout

Matches the last 2 digits of the 1st Prize (Top) or official 2-digit draw (Bottom).

Example 1st Prize = 843921 → 2D Top = 21 (90x)

19 Doors (19 ประตู)

19 Lines

Automatically places bets on all 19 two-digit numbers containing your key digit.

Example Key [7] → Bets 07, 17, 27... 70, 71... 79

Running (วิ่งบน / วิ่งล่าง)

3.2x / 4.2x

Select a single digit (0-9). Wins if that digit appears anywhere in the target result.

Example Top 3 = 921 → Running [9], [2], [1] win
